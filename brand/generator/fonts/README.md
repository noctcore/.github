# Font sources

These are unmodified source fonts for rebuilding outlined brand artwork.
Displaying the final SVGs does not load them. Both families use the SIL Open
Font License 1.1; complete notices are in `../licenses/`.

- Family: Manrope, variable weight TTF.
- Original filename: `Manrope[wght].ttf`; local filename: `Manrope.ttf`.
- Copyright 2018 The Manrope Project Authors.
- Source: [Google Fonts, pinned Manrope revision](https://github.com/google/fonts/blob/b31870aff700ab7a1d74fa0c6887d95beb9e0037/ofl/manrope/Manrope%5Bwght%5D.ttf).
- License: [upstream OFL](https://github.com/google/fonts/blob/b31870aff700ab7a1d74fa0c6887d95beb9e0037/ofl/manrope/OFL.txt).
- Used at weight 600 for the wordmark and display copy, 550 for supporting prose.
- SHA-256: `3ae11c49db0455a3cc33e37d380f20fdb8c7f8b41dc07625c177e3d87a9d6ae6`.
